خطوات رفع اقْرَأْ · التمهيديّ ت٣ — سقف التمارين 30→40 + «تحديث المعتمدة»
========================================================================
لا SQL ولا صوت ولا صور هذه المرّة (نصوص الحلقات والبطاقات والمكتبة لم تتغيّر — التمارين فقط 30→40).
الزيب: ATHAR-IQRA-PRE-T3.zip (15 ملفًا — التزام واحد).

الخطوة 1 — الرفع إلى GitHub (دقيقتان)
  https://github.com/aabdalaziz/training-evaluation-platform/upload/main
  فكّ الزيب واسحب المجلّدات الخمسة: lib · app · tests · tools · docs
  رسالة الالتزام: Iqra Pre-A1 T3: 40 exercises per lesson (level-aware cap) + admin option to update approved lessons in place
  → Commit changes → انتظر نشر Vercel (3–5 دقائق): https://vercel.com/dashboard
  (إن ظهر Error في Vercel أرسل لي أوّل سطر أحمر من السجلّ.)

الخطوة 2 — الاستيراد فوق الحلقات المعتمدة (الحلقات العشرون معتمدة في الإنتاج — لذلك الخيار الجديد)
  https://athar-portal.com/admin/iqra → تبويب «تمهيدي» → «استيراد حزمة محتوى»
  2.1 اختر الملف tools/iqra/packs/iqra-pack-PRE_A1-U01.json
  2.2 ✅ علِّم مربّع «تحديث الحلقات المعتمدة أيضًا (تبقى معتمدة)» — بجوار زرّ الاستيراد
  2.3 «فحص» → المتوقّع: 200 تمرينًا · 0 مشكلات · 0 تحذيرات
  2.4 «استيراد» → تظهر رسالة تأكيد «ستُستبدل بطاقات ومِران الحلقات المعتمدة…» → موافق
      المتوقّع: أُنشئت 0 · حُدّثت 5 · تُركت معتمدة 0 · بطاقات 78 · مِران 200 · مكتبة 2
  2.5 كرّر للحزم U02 (بطاقات 75) · U03 (80) · U04 (80) — مع تعليم المربّع في كلّ مرّة.
  ⚠ بلا تعليم المربّع: النتيجة «تُركت معتمدة 5» ولا شيء يتغيّر (الأمان القديم كما هو).
  بعدها في جدول «حلقات تمهيدي»: عمود «مِران» = 40 لكلّ الحلقات، والحالة «معتمدة» كما كانت (لا حاجة لإعادة الاعتماد).

الخطوة 3 — عين المتعلّم (دقيقة)
  https://athar-portal.com/iqra (حساب مسكَّن في Pre-A1) → افتح أيّ حلقة → محطّة المِران: «الزيارة 1 · 10 من 40»
  (السحب يبقى 10 لكلّ زيارة — أصبحت الحلقة 4 زيارات بدل 3).

ثمّ أرسل «تم» — وأطابق الحزم الأربع على GitHub وأحدّث الوثائق.
ملاحظة: لا تغيير في A1–C1 (سقفها 30 كما هو؛ السقف الجديد للتمهيديّ فقط).
